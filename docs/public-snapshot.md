# Public snapshot scope

This repository starts from a new Git root. Earlier application snapshots,
private host reports, remote configuration, original commit metadata and historical
branches/tags are intentionally not part of this candidate. Restricted provenance
records are retained outside it. This is a distribution boundary, not a claim of
independent invention or cleared ownership. Existing copyright and license notices
are preserved; an owner must review permissions before publication.

## Included

- SDK, Console, maintained native/staged examples, locked dependencies and tests.
- Domain-neutral documentation and fixtures instead of private-host identities,
  paths, deployment details, integration claims and URLs.
- ADKL-named Material theme with an indigo action accent, distinct failure colors
  and unchanged accessibility contrast requirements.
- Geometric bolt icons generated by `scripts/generate_icons.py`, not corporate
  brand assets. The generator uses only Python's standard library.
- Fallback fonts independently retrieved from public upstream URLs, byte-compared
  and documented with SHA-256 hashes in `deploy/portal/fonts/README.md`; accompanying
  font licenses remain included.

## Compatibility

Runtime behavior and dependency locks are preserved. Generic gateway configuration
names/model defaults remain compatibility APIs; they contain no bundled endpoint
or credential and still require host provisioning. The Console-internal theme
identifiers and palette change; no Python API migration is introduced. Customer
business rules, data and integration evidence do not become generic SDK claims
merely by changing names.

Some retained historical product/SDK assessments mention revisions from the
pre-public development repository. Those revisions are not present in this
clean-root candidate, and historical test results do not validate this snapshot.
Reproduce fresh checks using [development](development.md).

## Publication limits

Do not make an old hosting project public merely because a cleaned branch was
pushed. Old commits may remain accessible through merge requests, tags, forks,
artifacts or server retention. Use a new empty repository and push only the
approved branch; never mirror the restricted repository or its backup bundle.
See [community release gates](community-release.md) for rights review, public
contacts, safe CI, artifact identity and known acceptance requirements.

A textual identifier scan is evidence about its exact patterns and inputs, not
proof that all sensitive material is absent. Re-scan all objects, metadata, file
paths and archive members after any change. Keep restricted scan terms/results
outside the public candidate and never copy a developer's ignored files into a
release. No public visibility change, release tag or deployment is implied here.
